## Границы возможностей

- UI назначает уже объявленные в specification теги. Отдельного создания/редактирования определений тегов через UI нет; пустой проект не содержит тегов.
- Inspector logical relation поддерживает подпись и удаление. Теги/технология/стиль связи не имеют отдельного GUI control.
- Tag styling и правила вида сохраняются в исходниках, но отдельный полноценный авторинг specification/styles/filter rules через GUI не реализован.
- Hide/lock — transient presentation; источник/история/ZIP ими не изменяются. Отдельного редактирования порядка слоёв нет.
- Проверено в локальном Chromium desktop на конечном fixture и существующей browser matrix. Произвольная глубина/размер, CI/release, Safari/Firefox и human acceptance не заявляются.
