work_package: WP-13
status: active

## Objective

Repair the GUI-to-code persistence and semantic ownership boundaries without
changing the supported canvas feature set.

## Shared contract

- `EditorWorkspace` owns semantic sources, draft, revision, history, model and
  manual layouts.
- IndexedDB is the only durable workspace owner.
- Entry document identity is explicit and survives sorting, reload and ZIP.
- Invalid candidates preserve the last valid rendered model.
- Stale/conflicting saves fail closed and require explicit recovery.

## Parallel write scopes

- Persistence worker: `src/editor/indexeddb-workspace.ts` and its focused tests.
- Owner/guardrail worker: legacy runtime-owner files and `.ast-grep` rules/tests.
- Bundle/docs worker: `src/editor/workspace-bundle.ts` and contract docs.
- Integration owner: `contracts.ts`, `workspace.ts`, runtime hooks, app UI,
  migration tests, and final verification.

Workers must not edit another scope, reset unrelated changes, commit, or push.

## Non-goals

- cloud sync or collaborative editing;
- generic text merge;
- expansion of the brace/regex prototype;
- new DSL authoring families;
- direct filesystem persistence.

## Stop conditions

Stop and report if a migration would discard a valid envelope, if worker scopes
overlap, or if browser proof cannot identify the served checkout.

## Checks

Focused Vitest tests, `pnpm typecheck`, `pnpm build` for the app, ast-grep
rule tests/scan, and browser acceptance for reload, invalid input, multi-file
round trip, no-op history, and two-tab conflict recovery.
